# Память разговоров

Поиск по архивированным разговорам используя семантическое сходство или точное совпадение текста.

**Основной принцип:** Ищи прежде чем изобретать заново.

**Объяви:** "Я ищу в предыдущих разговорах по теме [тема]."

## Когда использовать

**Ищи когда:**
- Партнёр упоминает "мы обсуждали это раньше"
- Отлаживаешь похожие проблемы
- Ищешь архитектурные решения или паттерны
- Перед реализацией чего-то знакомого

**Не ищи когда:**
- Информация в текущем разговоре
- Вопрос о текущей кодовой базе (используй поиск по файлам)

## Использование в сессии

**Всегда используй подагентов** (экономия контекста в 50-100 раз).

Запускай поиск через `new_task`:
```
new_task(
  mode="ask",
  message="Найди в предыдущих разговорах информацию о [тема]. Используй инструмент поиска разговоров."
)
```

## Прямой поиск (ручной/CLI)

Если установлен инструмент поиска разговоров:

**Режимы:**
```bash
search-conversations "запрос"              # Векторное сходство (по умолчанию)
search-conversations --text "точный"       # Точное совпадение строки
search-conversations --both "запрос"       # Оба режима
```

**Флаги:**
```bash
--after ГГГГ-ММ-ДД    # Фильтр по дате
--before ГГГГ-ММ-ДД   # Фильтр по дате
--limit N             # Макс результатов (по умолчанию: 10)
--help                # Полное использование
```

**Примеры:**
```bash
# Семантический поиск
search-conversations "ошибки аутентификации React Router"

# Найти git SHA
search-conversations --text "a1b2c3d4"

# Временной диапазон
search-conversations --after 2025-09-01 "рефакторинг"
```

Возвращает: проект, дата, краткое изложение разговора, совпавший обмен, % сходства, путь к файлу.

## Примечание для Roo Code

В Roo Code история разговоров хранится в проектах VS Code. Для поиска по истории используй:
- Встроенный поиск VS Code по файлам `.jsonl` в директории проекта
- Или инструмент `execute_command` для поиска через grep по файлам истории

Путь к истории разговоров Roo: `~/.roo/projects/` или в директории проекта.
