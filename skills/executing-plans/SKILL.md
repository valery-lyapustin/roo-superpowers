# Выполнение планов

## Обзор

Загрузи план, критически проверь, выполняй задачи пакетами, сообщай для ревью между пакетами.

**Основной принцип:** Пакетное выполнение с контрольными точками для ревью архитектором.

**Объяви в начале:** "Я использую скилл Выполнение планов для реализации этого плана."

## Процесс

### Шаг 1: Загрузи и проверь план
1. Прочитай файл плана
2. Критически проверь — определи вопросы или опасения по плану
3. Если есть опасения: Подними их с партнёром перед началом
4. Если нет опасений: Создай задачи в `update_todo_list` и продолжай

### Шаг 2: Выполни пакет
**По умолчанию: Первые 3 задачи**

Для каждой задачи:
1. Отметь как в процессе
2. Следуй каждому шагу точно (план содержит небольшие шаги)
3. Запускай верификации как указано
4. Отметь как завершённую

### Шаг 3: Сообщи
Когда пакет завершён:
- Покажи что было реализовано
- Покажи вывод верификации
- Скажи: "Готов к обратной связи."

### Шаг 4: Продолжай
На основе обратной связи:
- Применяй изменения если нужно
- Выполняй следующий пакет
- Повторяй до завершения

### Шаг 5: Завершение разработки

После завершения и верификации всех задач:
- Объяви: "Я использую скилл Завершение ветки разработки для завершения этой работы."
- Переключись на скилл `finishing-a-development-branch`
- Следуй ему для верификации тестов, представления вариантов, выполнения выбора

## Когда остановиться и попросить помощи

**НЕМЕДЛЕННО останавливайся когда:**
- Встретил блокировщик в середине пакета (отсутствующая зависимость, тест падает, инструкция неясна)
- В плане критические пробелы мешающие началу
- Не понимаешь инструкцию
- Верификация раз за разом проваливается

**Спрашивай разъяснения вместо угадывания.**

## Когда возвращаться к ранним шагам

**Возвращайся к Проверке (Шаг 1) когда:**
- Партнёр обновляет план на основе твоей обратной связи
- Фундаментальный подход требует переосмысления

**Не форсируй через блокировщики** — останавливайся и спрашивай.

## Помни
- Сначала критически проверяй план
- Следуй шагам плана точно
- Не пропускай верификации
- Ссылайся на скиллы когда план говорит это
- Между пакетами: просто сообщай и жди
- Останавливайся когда заблокирован, не угадывай
