# Когда застрял — Диспетчеризация решения проблем

## Обзор

Разные типы застревания требуют разных техник. Этот скилл помогает быстро определить какой скилл решения проблем использовать.

**Основной принцип:** Сопоставляй симптом застревания с техникой.

## Быстрая диспетчеризация

| Как застрял | Используй этот скилл |
|------------------|----------------|
| **Спираль сложности** — Одно и то же реализовано 5+ способами, растут спецслучаи | `simplification-cascades` |
| **Нужна инновация** — Обычные решения неадекватны, не могу найти подходящий подход | `collision-zone-thinking` |
| **Повторяющиеся паттерны** — Одна и та же проблема в разных местах, изобретаю колёса | `meta-pattern-recognition` |
| **Принуждён допущениями** — "Это должно быть сделано так", не могу поставить под сомнение предпосылку | `inversion-exercise` |
| **Неопределённость масштаба** — Будет ли это работать в продакшне? Граничные случаи неясны? | `scale-game` |
| **Код ведёт себя неправильно** — Неправильное поведение, тест падает, неожиданный вывод | `systematic-debugging` |
| **Несколько независимых проблем** — Можно распараллелить исследование | `dispatching-parallel-agents` |
| **Первопричина неизвестна** — Симптом ясен, причина скрыта | `root-cause-tracing` |

## Процесс

1. **Определи тип застревания** — Какой симптом совпадает выше?
2. **Загрузи тот скилл** — Прочитай конкретную технику
3. **Применяй технику** — Следуй её процессу
4. **Если всё ещё застрял** — Попробуй другую технику или комбинируй

## Комбинирование техник

Некоторые проблемы требуют нескольких техник:

- **Упрощение + Мета-паттерн**: Найди паттерн, затем упрости все экземпляры
- **Столкновение + Инверсия**: Форсируй метафору, затем инвертируй её допущения
- **Масштаб + Упрощение**: Крайности раскрывают что устранить

## Помни

- Сопоставляй симптом с техникой
- Одна техника за раз
- Комбинируй если первая не работает
- Документируй что пробовал
